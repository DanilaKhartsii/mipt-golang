          Что происходит под капотом?
          
    БраузерGatewayВоркеры LedgerБаза данных
    
          
    Gateway передаёт массив в Ledger. Канал jobs раздаёт записи воркерам. Они проверяют сумму, категорию, дату и остаток бюджета, затем сохраняют расход.
    
          
    Коллектор читает канал results и собирает сводку. Ошибка одной записи не мешает остальным. Индекс ошибки начинается с нуля; порядок обработки может отличаться от порядка в массиве.
    
          
    Лимит категории проверяется под блокировкой в базе, поэтому одновременные записи не могут вместе превысить бюджет. Интерфейс получает итоговый ответ — ход отдельных воркеров API не передаёт.
